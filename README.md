## 🧑‍💻 About Me

I'm a graduate student at the **University of North Texas** with a **B.S. in Computer Science, Cybersecurity Concentration** from **Louisiana Tech University**, where I worked as a research and teaching assistant.

I build systems at the intersection of **machine learning, security, and constrained computing** — models that run where resources are scarce, and tools that detect when things go wrong.

- 📄 **Currently**: finishing a first-author working paper (**OrbitML** — fault-tolerant ML inference for satellites)
- 🎯 **Goal**: Ph.D. in machine learning + security for networked and cyber-physical systems

## 🔬 Research

### 🛰️ OrbitML — Fault-Tolerant AI Inference for Orbital Compute
> First-author working paper: keeping ML models running reliably on satellites, where radiation and hardware faults corrupt computation.
- Proposes a fault-tolerant inference architecture for orbital/edge platforms
- Open-source fault-injection simulator — results reproducible on a laptop
- In preparation for arXiv (cs.DC, cs.LG)
- **[View Repository](https://github.com/birajthapa007/OrbitML)**

### 🥽 Meta Quest 2 Security Research *(Completed, 2024)*
> How Android app permissions can be misused inside VR headsets.
- Built test apps with Unity + Oculus SDK to demonstrate risks and mitigations
